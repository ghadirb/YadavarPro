# یادآور پرو (Yadavar Pro)

اپلیکیشن مستقل یادآوری، جدا شده از بخش یادآوری [ghadirb/Maliar-Pro](https://github.com/ghadirb/Maliar-Pro).

`applicationId`: `com.ghadirb.yadavar`  
نسخه فعلی: **۱.۳.۰** (`versionCode` 4)

## این پروژه از کجا اومده

موتور یادآوری (`ReminderEntity`, انواع یادآوری، تکرار، AlarmManager, اعلان‌های
کنش‌دار انجام‌شد/بعداً/تماس) بر اساس معماری بخش یادآوری مالیار پرو ساخته شده، اما
**کد این پروژه بازنویسی‌شده و مستقل است**، نه کپی مستقیم.

### از برنچ `codex/reminder-finalize-v2` مالیار پرو:
- یادآوری بازه‌ای (`repeatIntervalDays` / `CUSTOM_INTERVAL`)
- انتخاب صدا برای هر یادآوری (۳۴ فایل صوتی فارسی در `res/raw`)
- خلاصه سررسیدشده / امروز / این هفته

### عمداً وارد نشد (وابسته به داده مالی):
- `DueDateReminderWorker` و فیلدهای لینک به چک/قسط/بدهی
- دستیار مالی، حسابداری، وضعیت مالی، کلیدهای API مالی

## قابلیت‌ها

- یادآوری ساده، تکراری، مکانی، دسته‌بندی (کار، شخصی، سلامت، دارو، خرید، قبض، مهمانی)
- سکوت شبانه سفارشی + حالت تمرکز + عبور یادآوری بحرانی از سکوت
- قالب‌های آماده، انتخابگر تاریخ شمسی، ویجت، پشتیبان JSON
- **دستیار یادآوری**: دستور فارسی روی دستگاه (بدون اینترنت) + گفتگوی آزاد اختیاری با کلید API خودت
- بیلد جدا برای کافه‌بازار / مایکت / نصب مستقیم
- خرید درون‌برنامه‌ای (ماهانه/سالانه) با همان الگوی مالیار پرو

## دستیار و چت

دستیار مالیار پرو به حسابداری و پیشنهاد سرمایه‌گذاری وصل است؛ آن بخش اینجا نیست و نباید باشد.

دستیار یادآور پرو فقط یادآوری است:

- بدون کلید: «فردا ساعت ۸ دارو بخور»، «هر روز ۹ صبح ورزش»، «یادآوری‌های امروز»، «سکوت شبانه روشن»
- با کلید اختیاری GapGPT / OpenAI-compatible در تنظیمات: گفتگوی آزاد، باز هم بدون موضوع مالی

## امضا و انتشار (بازار / مایکت)

راهنمای امضا: [docs/SIGNING.md](docs/SIGNING.md)  
راهنمای فروشگاه و پرداخت: [docs/STORE_SETUP_FA.md](docs/STORE_SETUP_FA.md)

کلید امضا **ثابت و مخصوص همین اپ** است (جدا از مالیار پرو). ورک‌فلو گیت‌هاب از Secretها می‌خواند و APK/AAB دیباگ و ریلیز می‌سازد.

```
Actions → Android Builds → Run workflow
  build_type: debug | release
  store: direct | bazaar | myket | all
```

## راه‌اندازی محلی

1. Android Studio (JDK 17) — Gradle sync
2. برای ریلیز محلی: `keystore.properties.example` را به `keystore.properties` کپی کن و `yadavar-release.jks` را کنارش بگذار
3. دیباگ: `./gradlew :app:assembleDirectDebug`
