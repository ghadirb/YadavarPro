# یادآور پرو (Yadavar Pro)

اپلیکیشن مستقل یادآوری، جدا شده از بخش یادآوری [ghadirb/Maliar-Pro](https://github.com/ghadirb/Maliar-Pro).

## این پروژه از کجا اومده

موتور یادآوری (`ReminderEntity`, انواع یادآوری، تکرار، AlarmManager, اعلان‌های
کنش‌دار انجام‌شد/بعداً/تماس) بر اساس معماری بخش یادآوری مالیار پرو ساخته شده، اما
**کد این پروژه بازنویسی‌شده و مستقل است**، نه کپی مستقیم - چون کد اصلی به دیتابیس
مالی مالیار پرو (چک، قسط، بدهی، بدهکار) و به سرویس پس‌زمینه‌ی آن برنامه گره خورده
بود و برای یک اپ مستقل معنی نداشت.

### چیزی که از برنچ `codex/reminder-finalize-v2` مالیار پرو وارد شد:
- یادآوری بازه‌ای (`repeatIntervalDays` / `CUSTOM_INTERVAL`)
- انتخاب صدا برای هر یادآوری (۳۴ فایل صوتی فارسی آماده در `res/raw` + امکان انتخاب
  فایل دلخواه از گوشی) - `ReminderSound.kt`
- خلاصه‌ی سررسیدشده/امروز/این‌هفته بالای لیست یادآوری‌ها

### چیزی که عمداً وارد نشد (چون به داده‌ی مالی مالیار پرو وابسته است):
- `DueDateReminderWorker` (یادآوری خودکار سررسید چک/قسط/بدهی/بدهکار)
- فیلدهای `linkedCheckId` / `linkedInstallmentId` / `linkedDebtId` / `linkedDebtorId`
- سرویس پس‌زمینه‌ی TTS قدیمی (که خودِ مالیار پرو هم به دلایل پایداری/باتری آن را
  حذف و با فایل‌های صوتی ضبط‌شده جایگزین کرده - این پروژه هم از ابتدا فقط فایل
  صوتی استفاده می‌کند، بدون سرویس گفتار پیوسته)

### قابلیت‌های تازه که مالیار پرو نداشت:
- ویجت صفحه اصلی برای یادآوری‌های نزدیک
- تقویم شمسی داخلی (`PersianCalendarHelper`) با تکرار سالانه‌ی درست بر مبنای سال
  شمسی، نه +۳۶۵ روز میلادی
- منطق تعطیلات ایران (پنج‌شنبه/جمعه) برای الگوهای تکرار «روزهای کاری»/«آخر هفته»

## راه‌اندازی

```
applicationId فعلی: com.ghadirb.yadavar   (placeholder - قبل از انتشار عوضش کن)
```

1. در Android Studio باز کن (Gradle sync خودکار انجام می‌شود).
2. برای فلیورهای بازار/مایکت، مقادیر `BAZAAR_IAB_PUBLIC_KEY` و
   `MYKET_IAB_PUBLIC_KEY` را در `gradle.properties` تنظیم کن - دقیقاً مثل
   `keystore.properties` در مالیار پرو (این پروژه فعلاً IAP ندارد، این مقادیر فقط
   برای وقتی لازمند که بخش پولی/Pro اضافه شود).
3. برای امضای ریلیز، یک `signingConfig` مشابه مالیار پرو اضافه کن (عمداً از این
   اسکلت حذف شده تا کلید مالیار پرو به‌اشتباه اینجا استفاده نشود).

## باقی‌مانده برای تکمیل
- صفحه‌ی تنظیمات (حالت اعلان، فعال/غیرفعال کردن انواع یادآوری)
- پشتیبان‌گیری/بازیابی JSON
- انتخابگر تاریخ شمسی داخل دیالوگ افزودن یادآوری (فعلاً از DatePicker میلادی
  استفاده می‌شود، `PersianCalendarHelper` آماده‌ی اتصال است)
- تکمیل geofence برای یادآوری مکانی (اسکلتش در `GeofenceHelper.kt` آماده است)
